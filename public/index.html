How it works

Create. Submit. Grade.

The whole loop from a new classroom to a graded submission, with nothing lost in email threads or shared drives.

1
Teacher creates a classroom

Pick a category and get a unique class code to share with the batch.

2
Students join with the code

Enrollment is instant. No approval queue, no spreadsheets.

3
Assignments go out

Each one is tied to a project stage, with a deadline and attached resources.

4
Faculty grade and reply

Marks and written feedback reach the student as soon as they are saved.

Main features

Everything a classroom needs.

Faculty get one place to post work and review it. Students get one list of what is due, what is submitted and what is graded.

Get started
Classrooms & class codes

Teachers create classrooms and share a unique code. Students join instantly.

Assignments & submissions

Set deadlines, attach resources and collect multi-file submissions with status tracking.

Grading & feedback

Review each submission, assign marks and write feedback from one screen.

Notifications

New assignments, resources and grades show up in the bell as they happen.

Role-based access

JWT authentication with separate student and teacher permissions, enforced on the server.

Works everywhere

Responsive on desktop, tablet and phone, in light or dark mode.
